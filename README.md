# Rift Duel

1v1 League of Legends trivia where the most obscure correct answer wins. Create a room, send your friend the invite link, and both answer the same "Name a…" prompts.

- Type any correct answer. Common answers stay near the surface; rare ones dive deeper and score more:
  Surface 100 · Twilight 300 · Midnight 500 · Abyss 750 · Trench 1000.
- Typos and common nicknames are accepted (e.g. "bork", "mf", "tabis", "yasou").
- No server needed: game messages are relayed through free public MQTT brokers over secure WebSockets (several at once for reliability), so it runs on GitHub Pages.

Add or re-tier answers by editing the `P` list in `index.html` (tier 1 = most obvious, tier 5 = most obscure).
