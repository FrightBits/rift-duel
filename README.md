# Rift Duel

1v1 League of Legends trivia in the browser. Create a room, send your friend the invite link, and race through the same questions. Faster correct answers score more points.

- No server needed: game messages are relayed through free public MQTT brokers over secure WebSockets (several at once for reliability), so it runs on GitHub Pages.
- 5, 10 or 15 rounds, 15 seconds per question, up to 1000 points per question.
- Keyboard: 1-4 or A-D to answer.

Add questions by editing the `Q` array in `index.html`.

Fan-made. Not affiliated with or endorsed by Riot Games.
